# Repository Context

## Project purpose
This repository contains a lightweight browser-based Memory (Concentration) card game. It is implemented as a single HTML file with embedded CSS and JavaScript, so it runs directly in a browser without any framework or package installation.

The game lets players:
- flip cards to find matching pairs
- switch between 4x4 and 6x6 board sizes
- track moves and elapsed time
- rate performance with a star system
- save best scores in local browser storage
- use keyboard navigation for accessibility

## What the repo does
The app is a classic memory matching game:
- cards are shuffled at the start of each round
- the user reveals two cards at a time
- matching pairs stay visible
- the timer starts when the first card is flipped
- the game ends when all pairs are matched
- the player receives a win summary and best-score history

## Stack and implementation
- HTML for structure
- CSS for layout, styling, card flip animation, and responsive behavior
- JavaScript for gameplay logic, scoring, timer, local storage, and accessibility features
- no external libraries or dependencies
